AIDevance File Manager — файловый менеджер для Android

Устроен как Проводник Windows: папки телефона деревом и одинаковые действия везде — открыть, скопировать, перенести, переименовать, удалить в корзину, найти. Ранняя версия: сейчас работает с памятью телефона, закрытой зоной (Secure Folder) и Google Drive, карта памяти — в следующих версиях.

Что умеет сейчас

  • Дерево папок, как в Проводнике. В дереве — память телефона, закрытая зона, Google Drive, недавние файлы и корзина.
  • Закрытая зона — Secure Folder у Samsung и подобные: её папки в том же дереве, из одного приложения; копирование и перенос между зонами, файлы из её Download.
  • Google Drive каждого подключённого аккаунта: «Подключить Google Drive» → выбор аккаунта телефона → «Разрешить», без пароля. «Мой диск» целиком и «Доступные мне», те же действия, что с файлами телефона; документы Google копируются как файлы Office. Пока Google проверяет приложение, сначала он покажет окно «приложение не проверено»: «Дополнительно» → продолжить.
  • Файлы из других облаков (OneDrive, Облако Mail и т.п.) — программа показывает облачные приложения телефона и открывает окно выбора самого облака: скопировать или перенести в любое место.
  • Действия с файлами. Открыть, скопировать, вырезать и вставить, переименовать, создать папку, посмотреть свойства — кнопками на виду. Скопированный файл можно вставить и в другую программу, например в Telegram.
  • Корзина. Удалённое можно вернуть или удалить навсегда; «Очистить корзину» — одной кнопкой.
  • Поиск в папке и по всему телефону.
  • Недавние файлы — по дням, с путём и размером.
  • Поделиться через программы, установленные на телефоне.
  • Обновления — в меню ⋮: приложение само проверяет новую версию на GitHub и ставит её поверх.

Как установить

  • Откройте AIDevance-File-Manager.apk на телефоне и разрешите установку из этого источника, если телефон спросит.
  • При первом запуске разрешите «Доступ ко всем файлам» — без него файловый менеджер не видит папки телефона.
