AIDevance File Manager — file manager for Android

Built like Windows Explorer: the phone's folders as a tree and the same actions everywhere — open, copy, move, rename, delete to the trash, find. Early version: it works with the phone's memory today; the private zone, Google Drive and the memory card come in the next versions.

Download for AndroidAIDevance-File-Manager.apk, version 0.1.2, Android 8 and newer

All release files and SHA-256

What it does now

  • Folder tree, like Explorer. The tree holds the phone's memory, recent files and the trash.
  • File actions. Open, copy, cut and paste, rename, new folder, properties.
  • Trash. Deleted files can be brought back or deleted for good.
  • Search in a folder and across the whole phone.
  • Recent files — by day, with path and size.
  • Share through the apps installed on the phone.

Coming next

  • The private zone — Samsung's Secure Folder, "Private space" on Android 15+ and the like — in the same tree, from one app.
  • Google Drive of every connected account.
  • The memory card.
  • Google Play.

How to install

  • Open AIDevance-File-Manager.apk on the phone and allow installing from this source if the phone asks.
  • At first start allow "All files access" — a file manager needs it to see the phone's folders.
