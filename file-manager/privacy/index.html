AIDevance File Manager

Политика конфиденциальности

Действует с 10 ноября 2026 г. Относится к приложению для Android AIDevance File Manager (пакет com.aidevance.filemanager), разработчик — AIDevance.

Коротко

  • У приложения нет своих серверов. Оно не собирает, не хранит, не продаёт и не передаёт личные данные; в нём нет аналитики, рекламы и слежения.
  • Ваши файлы идут только между телефоном и вашим собственным Google Drive, напрямую, по шифрованному соединению (HTTPS).

Файлы на телефоне

Приложение просит разрешение Android «Доступ ко всем файлам», чтобы показывать файлы памяти телефона и карты и работать с ними, как любой файловый менеджер. Файлы читаются и меняются только по вашему действию (открыть, копировать, перенести, переименовать, удалить, поделиться). Никуда ничего не отправляется, пока вы сами не скопируете или не перенесёте файл в Google Drive или не отправите его выбранной вами программе.

Google Drive и данные пользователя Google

  • К чему доступ. Когда вы нажимаете «Подключить Google Drive» и разрешаете доступ, приложение получает доступ к Google Drive этого аккаунта (область https://www.googleapis.com/auth/drive): имена, размеры, даты и папки файлов Drive, их содержимое — когда вы их открываете, копируете, переносите или отправляете, — и сколько места занято и сколько всего.
  • Зачем. Только чтобы показать ваш Drive в дереве папок и выполнить выбранные вами действия: показать папки, открыть, копировать и переносить файлы между Drive и телефоном, переименовать, создать папку, удалить в корзину Drive и восстановить, удалить навсегда, искать по имени, показать недавние файлы, сохранить обратно файл, изменённый в другой программе.
  • Куда идут данные. Напрямую между телефоном и серверами Google. Копии файлов, которые вы открываете или отправляете, временно лежат в закрытом кэше приложения на телефоне. Ничего не отправляется AIDevance или кому-либо ещё.
  • Вход. Приложение никогда не видит пароль Google. Доступ выдаёт Google через аккаунт, уже добавленный на телефон; ключ доступа хранит Android на телефоне.
  • Отключение. Долгое нажатие на аккаунт в дереве → «Отключить Google Drive»: приложение убирает аккаунт и просит Google отозвать доступ. Отозвать можно и в любой момент на myaccount.google.com/permissions. Файлы в Drive не трогаются.
  • Не передаётся, не читается людьми, не обучает ИИ. Данные пользователя Google не передаются третьим лицам, не используются для рекламы, не читаются людьми и не используются для разработки, улучшения или обучения моделей ИИ и машинного обучения.

Использование и передача AIDevance File Manager в любое другое приложение информации, полученной от API Google, соответствует Google API Services User Data Policy, включая требования Limited Use.

Файлы из других облаков

«Взять файлы из другого облака» открывает окно выбора файлов Android; приложение получает только выбранные вами там файлы.

Обновления

Чтобы проверить новую версию, приложение скачивает маленький файл (latest.json) и, если вы согласитесь, новый файл приложения с GitHub (github.com/AIDevance). Личные данные с этими запросами не отправляются.

Хранение и удаление

Приложение хранит на телефоне только свои настройки (например, какие аккаунты Google подключены) и временный кэш. Удаление приложения удаляет их. Отключение аккаунта убирает его из приложения.

Дети

Приложение не предназначено для детей младше 13 лет.

Изменения
