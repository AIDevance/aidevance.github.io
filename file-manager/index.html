AIDevance File Manager — file manager for Android

Built like Windows Explorer: the phone's folders as a tree and the same actions everywhere — open, copy, move, rename, delete to the trash, find. Early version: it works with the phone's memory, the private zone (Secure Folder) and Google Drive today; the memory card comes in the next versions.

Download for AndroidAIDevance-File-Manager.apk, version 0.3.0, Android 8 and newer

All release files and SHA-256

What it does now

  • Folder tree, like Explorer. The tree holds the phone's memory, the private zone, Google Drive, recent files and the trash.
  • The private zone — Samsung's Secure Folder and the like: its folders in the same tree, from one app; copy and move between the zones, files from its Download.
  • Google Drive of every connected account: Connect Google Drive → pick an account of the phone → Allow, no password. The whole My Drive and Shared with me, the same actions as on the phone; Google documents are copied as Office files. Until Google has reviewed the app, connecting is open to test accounts only.
  • Files from other clouds (OneDrive and the like) — through the file window: copy or move them anywhere.
  • File actions. Open, copy, cut and paste, rename, new folder, properties.
  • Trash. Deleted files can be brought back or deleted for good.
  • Search in a folder and across the whole phone.
  • Recent files — by day, with path and size.
  • Share through the apps installed on the phone.
  • Updates — in the ⋮ menu: the app checks GitHub for a new version itself and installs it over the old one.

Coming next

  • The memory card.
  • Google Play.

How to install

  • Open AIDevance-File-Manager.apk on the phone and allow installing from this source if the phone asks.
  • At first start allow "All files access" — a file manager needs it to see the phone's folders.
