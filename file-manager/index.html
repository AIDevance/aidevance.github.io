AIDevance File Manager — file manager for Android

Built like Windows Explorer: the phone's folders as a tree and the same actions everywhere — open, copy, move, rename, delete to the trash, find. Early version: it works with the phone's memory, Secure Folder and Google Drive today and keeps private files in the encrypted Private Folder; the memory card comes in the next versions.

Download for AndroidAIDevance-File-Manager.apk, version 0.4.1, Android 8 and newer

All release files and SHA-256

What it does now

  • Folder tree, like Explorer. The tree holds recent files, the gallery, the phone's memory, Secure Folder, Private Folder, Google Drive and the trash. The phone's service folders (Android, Alarms…) go last, apart from yours.
  • Private Folder — an encrypted folder. Tap it and enter the PIN — it works like any folder; it closes by itself after 5 minutes without actions, or by the lock. Files and their names are kept encrypted: without the PIN neither other apps nor a computer connected to the phone can read them. To Private moves files in (the originals are deleted past the trash), Take out brings them back. A recovery key in case the PIN is forgotten; optionally fingerprint unlock and a wipe PIN: entered instead of the PIN, it erases everything inside.
  • Gallery — the phone's photos and videos by albums, as thumbnails.
  • Secure Folder — the phone's second zone (Samsung's Secure Folder) and the like: its folders in the same tree, from one app; copy and move between the zones, files from its Download.
  • Google Drive of every connected account: Connect Google Drive → pick an account of the phone → Allow, no password. The whole My Drive and Shared with me, the same actions as on the phone; Google documents are copied as Office files. Until Google has reviewed the app, Google shows an "unverified app" screen first: Advanced → continue.
  • Files from other clouds (OneDrive and the like) — the app lists the cloud apps on the phone and opens the cloud's own file window: copy or move the files anywhere.
  • File actions. Open, copy, cut and paste, rename, new folder, properties — as buttons on view. Copied files can be pasted into other apps too (Telegram, for example).
  • Trash. Deleted files can be brought back or deleted for good; Empty trash in one tap.
  • Search in a folder and across the whole phone.
  • Recent files — by day, with path and size.
  • Share through the apps installed on the phone.
  • Inside other apps. When an app asks you to choose a file, File Manager offers its own window — phone, Gallery, Recent, Google Drive, Private Folder. In the Android Open / Save window your Drive accounts appear as «AIDevance · Google Drive»: open from Drive and save into it. Private Folder is there only while it is open.
  • Updates — as in Pulsar Direct: the app checks GitHub at every start and every 6 hours; a new version shows as a yellow bar at the top with «Install now», and is downloaded by itself over Wi-Fi.

How to install

  • Open AIDevance-File-Manager.apk on the phone and allow installing from this source if the phone asks.
  • At first start allow "All files access" — a file manager needs it to see the phone's folders.
